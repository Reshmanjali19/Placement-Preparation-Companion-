Important Interview Notes

This page contains quick revision notes and key concepts useful for technical interviews and placement preparation.

HTML Concepts

  • HTML stands for HyperText Markup Language.
  • Used to structure web pages.
  • Semantic tags improve readability and SEO.
  • Forms are created using the <form> tag.
  • Common tags: header, nav, section, footer.

Python Concepts

  • Python is an interpreted programming language.
  • Functions are defined using def.
  • Lambda functions are anonymous functions.
  • Map, Filter, Reduce are functional programming tools.
  • Lists are mutable; tuples are immutable.

SQL Concepts

  • SQL is used to manage relational databases.
  • SELECT retrieves data from tables.
  • WHERE filters records.
  • GROUP BY is used with aggregate functions.
  • JOIN combines multiple tables.

HR Interview Tips

  1. Introduce yourself confidently.
  2. Explain projects clearly.
  3. Highlight strengths with examples.
  4. Maintain eye contact and positive attitude.
  5. Ask thoughtful questions at the end.
